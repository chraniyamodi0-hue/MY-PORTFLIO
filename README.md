# Chiranya Modi — BCA Portfolio

A professional, responsive personal portfolio website for **Chiranya Modi**, a BCA student with an interest in **Artificial Intelligence and Generative AI**.

The portfolio presents personal information, technical and soft skills, hobbies, education, and contact details in a clean and modern single-page layout.

## ✨ Features

- Responsive single-page portfolio
- Fixed navigation bar with smooth scrolling
- Hero section with personal introduction
- About Me section
- Skills section
- Soft Skills section
- Hobbies section
- Education section
- Contact section
- Mobile-friendly responsive design
- Interactive navigation highlight on scroll
- Modern gradient-based visual design
- No external frameworks required

## 🛠️ Technologies Used

- **HTML5** — Website structure and content
- **CSS3** — Styling, layout, gradients, responsive design, and animations
- **JavaScript** — Scroll-based active navigation effect

## 🚀 How to Run

No installation or server setup is required.

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The portfolio will open in your web browser.

You can also use **VS Code** and open `index.html` with a Live Server extension.

## 🎨 Customization

You can easily customize the portfolio by editing `index.html`.

### Change Name

Find the hero section and replace the existing name with your name.

### Change Skills

Add, remove, or edit the skill tags inside the Skills section.

### Change Education

Update the degree, college, university, and academic year according to your details.

### Change Contact Information

Update the email address and other contact information in the Contact section.

### Change Colors

The main website colors are defined in the CSS variables:

```css
:root {
  --primary: #6c63ff;
  --secondary: #8b5cf6;
  --dark: #111827;
  --text: #374151;
  --light: #f8fafc;
  --white: #ffffff;
  --border: #e5e7eb;
}
```
